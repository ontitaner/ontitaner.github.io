# EMS AGC二次调频：从ACE到机组响应的闭环控制

本课程面向储能/新能源场站 EMS 开发者、并网调试工程师与电站运维人员，系统阐述 AGC（自动发电控制）在新能源场站侧的技术要求与工程实现。课程从调度主站的区域控制偏差（ACE）出发，沿 IEC104 指令链路逐级下沉至 EMS 的校验、分配、安全闭锁与 PCS 执行，最终以 K1/K2/K3 三项指标闭环到月度考核结算与辅助服务市场收益分析。

课程内容以《面向新型电力系统的光储系统并网关键技术》（中国电力科学研究院，2023 年 8 月）中 AGC 相关技术要求为骨架，补充 EMS 侧的工程实现视角。文中引用的规程条款仅作为理解口径，现场参数一律以项目适用的调度规程与并网协议为准。

**入口章节**：[00 AGC二次调频：从调度ACE到全场出力的闭环控制链路](00_AGC闭环控制链路.md)

## 前置依赖

本课程强烈建议先完成 [EMS 一次调频技术要求与实现](../ems-primary-frequency-regulation/README.md)，理解一次调频（比例有差调节，P）与 AGC（积分无差调节，I）在控制理论层面的分工与在功率合成公式中的叠加关系。

## 学完能做什么

- 拿到一份新的省网 AGC 调度细则，能在 30 分钟内定位到影响 EMS 开发的条款；
- 独立完成调节速率（K1）、响应时间（K2）、调节精度（K3）与可调范围四项指标的工程换算与代码落地；
- 设计风光储异构场站的 AGC 功率分配策略，处理差异化能力约束与动态补差；
- 诊断 AGC 月度考核不合格的根因——定位到通信层、分配层还是执行层；
- 设计 AGC 并网联调试验方案，用带时标的四时刻数据（T_cmd/T_recv/T_start/T_end）形成可追溯的验收证据链；
- 在里程补偿与容量补偿两种机制下做出 AGC 投运策略的经济性决策。
