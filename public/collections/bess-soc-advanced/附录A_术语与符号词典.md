## A.6 符号与单位约定

全教程统一遵守以下约定，与正文公式一致：

| 约定项 | 规定 |
|---|---|
| 电流 / 功率方向 | **放电为正、充电为负**（电池放出能量时 I>0） |
| SOC 数值 | 代码中用 0～1，正文叙述用百分比（%）；两者等价 |
| 电阻 | 单位欧姆（Ω）；R0、R1 示例值为 mΩ 量级 |
| 电容 | 单位法拉（F）；C1 示例 20000 F |
| 时间 | 采样周期、时间常数单位秒（s）；时长换算按 1 h = 3600 s |
| 容量 | 电荷口径用安时（Ah），能量口径用千瓦时（kWh）；C = C_Ah × V / 1000 近似为 kWh |
| 电压 | 单位伏（V）；端电压、OCV 均为单体电压量级（LFP 约 2.9～3.45 V） |
| 协方差 / 方差 | 无量纲（对 SOC 而言），σ_SOC 与 SOC 同口径（0～1） |
| 效率 | 0～1 之间；放电路径效率 η_dis、均衡转移效率 η 等 |
| 教学参数标注 | 所有示例参数标 `[教学示例]`，现场以规格书、定值单、项目配置为准 |

**核心符号速查**：

```text
C    额定容量（Ah 或 kWh）        R0   欧姆内阻（Ω）
R1   极化电阻（Ω）                C1   极化电容（F）
τ    时间常数 = R1·C1（s）        a    RC 衰减因子 = exp(−Δt/τ)
I    电流（A，放电为正）          V_t  端电压（V）
OCV  开路电压（V）                V1   RC 极化电压（V）
SOC  荷电状态（0～1）             SOH  健康状态（0～1）
P    协方差矩阵（2×2）            Q/R  过程/量测噪声
H    量测雅可比 [dOCV/dSOC, −1]   K    卡尔曼增益
σ    标准差                       η    效率（0～1）
```
