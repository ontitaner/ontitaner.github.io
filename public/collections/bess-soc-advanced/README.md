# 储能电池荷电状态估计与均衡进阶

**一句话**：把储能行业两个常被当作"黑盒"的东西——SOC（State of Charge，荷电状态）估计算法与电芯均衡——用零依赖的合成仿真逐一打开，看懂里面到底在算什么。

## 这份教程是什么

面向有储能 EMS / 电池软件背景、已经掌握安时积分与规则校准的工程师，深入到状态估计算法内核（等效电路模型、参数辨识、扩展卡尔曼滤波、不确定度传播）和单体一致性与均衡（不一致机理、被动均衡、主动均衡、协同验证）。

设计原则：

- **学习资料**，不是生产级 BMS 固件。目标是直观模拟、看懂算法，而非工程验收框架。
- **合成数据**：用物理模型正向生成"藏着已知 SOC 真值"的电流/电压序列，让估计器从错误初值出发、断言它收敛回真值。离线、可复现、不联网。
- **零依赖**：所有教学代码仅用 Python 标准库，裸 Python 3 即可运行，无需安装任何第三方库。
- **零耦合、可独立交付**：本目录整体可打包成 zip 单独交给他人，不依赖任何外部代码。
- **每篇自包含**：正文不含任何链接，需要引用其他篇或概念时就地用文字复述；每段教学代码块可整块拷贝直接运行。

## 如何运行代码

每篇的教学代码都有一份落盘镜像在 `lab/` 目录，既可单独直跑看"自检通过"，也可用 pytest 批量回归：

```bash

python3 ch01_ecm_pulse.py

# 批量回归（八篇一起）
```

## 统一示例（全教程共用同一电芯与剖面）

九篇所有公式手算、代码、图表都围绕同一个物理对象展开，跨篇形成连贯叙事：

| 参数 | 值 | 含义 |
|---|---|---|
| C | 100 Ah | 单体额定容量 |
| R0 | 1.0 mΩ | 欧姆内阻 |
| R1 | 0.8 mΩ | 极化电阻 |
| C1 | 20000 F | 极化电容（τ = R1·C1 = 16 s） |
| OCV-SOC | LFP 13 点表 | 平台区约 1 mV/1% SOC，陡峭区约 20 mV/1% |
| 真值初值 | SOC = 50% | 仿真起点 |
| 估计器初值 | SOC = 70% | 故意设错 +20%，考察收敛 |
| 电池组 | 4 单体 60/58/55/45% | 均衡篇用，每簇 100 Ah |

这些数值均为 `[教学示例]`，现场以电芯规格书、BMS 定值单和项目配置为准。
