## 学完能做什么

- 拿到一份新的省网调度细则，能在 30 分钟内定位到影响 EMS 开发的条款；
- 独立完成死区、调差率、限幅、方向四个参数的换算与代码落地；
- 按性能指标倒推端到端延迟预算，判断功能该放在 EMS 还是 PCS；
- 说清楚"调节偏差考核不合格"到底是算法问题、数据问题还是口径问题；
- 设计一次调频试验方案，并用带时标的数据形成验收证据。

## 新手最常问的五个问题

**Q1：为什么频率掉了就要多发？**

频率是发电和用电平衡的"温度计"。用电 > 发电 → 同步发电机转子减速 → 频率下跌。一次调频做的就是用备用出力补上缺口，阻止频率继续掉。

**Q2：下垂公式里那个负号到底是干嘛的？**

`ΔP = −K × Δf`。频率低时 `Δf = −0.1 Hz`，如果没有负号，`ΔP = K × (−0.1)` = 负值 = 减出力——频率会更低。负号的作用是反转逻辑：频率低 → 出力增。

**Q3：积分电量和家里电表上的度数是一回事吗？**

不完全一样。家用电表计的是实际消耗的 kWh。一次调频的积分电量是**对"调频出力增量"在频率事件持续时间内积分**，单位也是 kWh，但它只计调频动作期间的增量部分，不是整个场站的总发电量。

**Q4：如果频率一直在死区内波动，一次调频是不是永远不工作？**

是的。死区 ±0.06 Hz 的意思是：频率在 49.94~50.06 Hz 之间时，一次调频**不动作**。这是故意设计的——正常负荷波动在 ±0.05 Hz 以内司空见惯，如果每次都响应，机械部件会过早疲劳、储能电池会被反复浅充浅放。

**Q5："算法算对了"为什么还会考核不合格？**

因为考核不是只看你的代码输出，它看的是"理论值 vs 实际出力"的积分比较。你的代码算出 ΔP = 4.0 MW，但如果死区选错了类型、方向约定和别人反了、PCS 的 ramp rate 限住了实际出力、或者并网点测点和你用的测点不一样——那么"实际出力"就和你算的不一样。09 章汇总了最常出错的十一个场景。
