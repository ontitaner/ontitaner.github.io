## A.1 符号表【必懂】

| 符号 | 名称 | 含义 | 单位 | 典型取值 |
|---|---|---|---|---|
| fn | 额定频率 | 国内同步电网为 50 Hz | Hz | 50 |
| f | 实测频率 | 并网点或指定测点的频率 | Hz | 49.8~50.2 |
| Δf | 频率偏差 | `f − fn`，频率低为负 | Hz | −0.2~+0.2 |
| Δf_eff | 有效频率偏差 | 过死区处理后的偏差 | Hz | 0~±0.2 |
| δ | 调差率（调差系数） | 频率变化额定频率的 δ 时出力变化 100% Pn | % | 2%~6% |
| K | 下垂系数 | `Pn / (δ × fn)` | MW/Hz | 20~100 |
| Pn | 额定有功 | 场站或机组的额定有功功率 | MW | 10~200 |
| P | 实际出力 | 当前有功功率 | MW | — |
| ΔP | 调频增量 | 一次调频带来的出力变化 | MW | ±10% Pn |
| t0.1 | 响应滞后时间 | 频率越死区 → 出力开始可靠变化 | s | ≤2（山西 ≤3） |
| t0.9 | 响应时间 | 频率越死区 → 达到目标变化量的 90% | s | 风电 ≤12、光伏 ≤5 |
| ts | 调节时间 | 频率越死区 → 出力进入 ±1% Pn 稳定带 | s | ≤15 |
| W_theory | 理论积分电量 | 对理论出力积分 | MWh | — |
| W_actual | 实际积分电量 | 对实际出力积分 | MWh | — |
| H | 惯性时间常数 | 满功率下转子动能可支撑的秒数 | s | 2~6 |

### 符号的三个易错点

| 易错点 | 说明 |
|---|---|
| δ 的分母是 fn 还是 100 | 公式 `δ = (Δf/fn)/(ΔP/Pn)`，分母是 fn（50），不是 100 |
| K 与 Pn 成正比 | 扩容后 K 必须重算，硬编码会改变实际调差率 |
| Δf 的符号 | 频率低为负，而 ΔP 为正（多发），公式里靠一个负号实现 |

## A.2 术语表【必懂】

| 术语 | 定义 | 与 EMS 的关系 |
|---|---|---|
| 一次调频 | 电源根据本地频率偏差自动、快速调整有功出力，属于分散式、秒级、有差调节 | 本课程主题；增量叠加在 AGC 基点上 |
| 快速频率响应 | 新能源场站参与一次调频时常用的表述，强调响应速度快 | 与一次调频在工程上基本同义 |
| 死区 | 不触发调频的频率区间 | 决定"什么时候动"，有平移/削平两种实现 |
| 调差率 | 描述下垂陡峭程度的无量纲比例 | 决定"动多少" |
| 限幅 | 一次调频出力的上下界 | 决定"最多动多少"，可上下不对称 |
| 下垂控制 | 出力与频率偏差成比例的控制方式 | 一次调频的核心算法 |
| 惯量 | 同步机转子储存的动能对频率变化的抵抗能力 | 新能源不天然提供，需控制模拟 |
| RoCoF | 频率变化率（Rate of Change of Frequency） | 决定事故初期频率跌得多快 |
| 构网型 | 主动建立电压与频率、提供惯量与支撑的控制方式 | 高于一次调频的支撑层级 |
| 积分电量 | 功率对时间的积分，单位 kWh/MWh | 一次调频考核的基本单位 |
| 闭锁 | 因异常暂停功能的状态 | 需按斜坡退出增量，不能直接清零 |
| 理论出力 | 按规程口径由频率反算出的应有出力 | 考核基准，必须独立实现 |
| 可执行出力 | 经能力校验后可实际执行的出力 | 受设备容量、SOC、最低出力限制 |

## A.3 易混词对照【必懂】

同一件事在不同文件里叫法不同，是现场争议的主要来源。

| 你可能看到的写法 | 统一理解 | 注意 |
|---|---|---|
| 调差率 / 调差系数 / 下垂率 / 下垂系数 | 概念相关但**不是同一个量** | "调差率"是无量纲比例；"下垂系数"通常指 K（MW/Hz） |
| 限幅 / 最大调节量 / 调节上限 / 功率限幅 | 一次调频出力上下界 | 必须确认是否上下对称 |
| 死区 / 阈值 / 盲区 / 不灵敏区 | 不动作的频率区间 | 必须确认半宽还是全宽（±0.05 还是 0.1） |
| 响应时间 / 响应滞后时间 / 调节时间 | 三个不同指标 | 见 A.1 的 t0.1 / t0.9 / ts |
| 一次调频 / 快速频率响应 / 快速调频 | 工程上多指同一功能 | 但个别文件可能定义不同 |
| 额定出力 / 额定容量 / 装机容量 | 通常都指 Pn | 需确认是交流侧还是直流侧 |
| 控制偏差 / 调节偏差 / 调节精度 | 实际与理论的差异 | 需确认按 Pn 还是按当前出力为基准 |

### "死区是半宽还是全宽"

这是最容易出错的细节之一：

```text
写法 A：死区 ±0.05 Hz     → 半宽 0.05，不动作区间 49.95~50.05（宽 0.1）
写法 B：死区 0.1 Hz       → 可能是全宽，即 ±0.05
写法 C：死区 50±0.05 Hz   → 明确是半宽
```

**处理原则**：配置里只存**半宽**（`deadband_hz`），文档里注明"半宽"。遇到"死区 0.1 Hz"这种写法，先与细则确认再配置。

## A.4 公式速查【必懂】

```text
① 频率偏差        Δf = f − fn

② 死区处理
   平移型          Δf_eff = sign(Δf) × max(0, |Δf| − 死区)
   削平型          Δf_eff = 0（|Δf| ≤ 死区）；否则 Δf_eff = Δf

③ 下垂系数        K = Pn / (δ × fn)

④ 调频增量        ΔP = −K × Δf_eff

⑤ 限幅            ΔP_lim = clamp(ΔP, −限幅_下, +限幅_上)

⑥ 能力校验
   上调空间        up   = min(设备上限 − 当前出力, 限幅_上)
   下调空间        down = min(当前出力 − 最低出力, 限幅_下)
   ΔP_exec         = clamp(ΔP_lim, −down, +up)

⑦ 达到限幅的频率点
   |Δf|_lim = 死区 + 限幅 / K = 死区 + 限幅 × δ × fn / Pn

⑧ 指令合成        P_total = clamp(P_agc + ΔP_exec, 运行下限, 运行上限)

⑨ 积分电量        W = ∫ ΔP dt

⑩ 完成率          完成率 = W_actual / W_theory
```

### 手算示例（一次走完）

`Pn = 100 MW`、`δ = 3%`、削平型死区 `±0.06 Hz`、限幅 `±10 MW`、`f = 49.88 Hz`：

```text
Δf      = 49.88 − 50 = −0.12 Hz
Δf_eff  = −0.12（|−0.12| > 0.06，削平型不削减）
K       = 100 / (0.03 × 50) = 66.67 MW/Hz
ΔP      = −66.67 × (−0.12) = +8.00 MW
限幅    = clamp(8.00, −10, +10) = +8.00 MW
```

## A.6 单位与换算【必懂】

| 换算 | 关系 |
|---|---|
| 功率 | 1 MW = 1000 kW |
| 电量 | 1 MWh = 1000 kWh |
| 功率 × 时间 → 电量 | `1 MW × 1 h = 1 MWh`；`1 MW × 1 min = 1/60 MWh ≈ 0.0167 MWh` |
| 频率偏差 | 1 Hz = 1000 mHz；0.003 Hz = 3 mHz |
| 调差率 ↔ 频率范围 | `δ = 2%` → 满功率对应 `1 Hz`；`δ = 3%` → `1.5 Hz` |
| 标幺值 | `ΔP/Pn` 与 `Δf/fn` 都是标幺量，δ 是两者之比 |

### 常见单位错误

| 错误 | 后果 |
|---|---|
| kW 当 MW 上送 | 调度看到 100 倍数值 |
| 电量按 W 算 | 结算金额差 10⁶ 倍 |
| 时间用分钟而非小时 | 积分电量差 60 倍 |
| mHz 当 Hz 配置 | 死区变成 0.00006 Hz，功能形同虚设 |

## 自测

1. 调差率与下垂系数有什么区别？分别怎么算？
2. "死区 0.1 Hz"这句话为什么有歧义？配置时应该存什么？
3. `Pn = 50 MW`、`δ = 2%`，K 是多少？限幅 `10% Pn` 对应多少 MW？
4. 为什么说"限幅必须确认是否上下对称"？
5. 把电量从 kW·min 换算成 MWh，系数是多少？

<details>
<summary>参考答案</summary>

1. 调差率 δ 是无量纲比例，定义为 `(Δf/fn)/(ΔP/Pn)`；下垂系数 K 是 `Pn/(δ × fn)`，单位 MW/Hz。δ 描述"陡峭程度"，K 是直接用于计算的斜率。
2. 因为它可能是全宽（不动作区间 0.1 Hz，即 ±0.05），也可能是半宽（±0.1）。配置时统一存**半宽** `deadband_hz`，并在文档中注明。
3. `K = 50/(0.02×50) = 50 MW/Hz`；限幅 `10% × 50 = 5 MW`。
4. 因为部分区域（如东北）要求下调 20%、上调 10%，不对称。若代码只支持单一限幅值，某一方向的调节能力会被削掉，导致该方向完成率偏低。
5. `1 kW × 1 min = 1/60 kWh = 1/60000 MWh ≈ 1.67×10⁻⁵ MWh`。即 kW·min 换算为 MWh 的系数是 `1/60000`。

</details>
