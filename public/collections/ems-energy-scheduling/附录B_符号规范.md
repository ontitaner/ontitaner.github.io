# 附录B 符号规范

> [课程首页](README.md)

本附录是本课程**正负号与单位的唯一真相来源**。所有正文手算、概念实现与 `lab/ems_lab/` 模块均以此表为准。

## B.1 方向约定（全课程一致）

| 物理量 | 正方向约定 | 说明 |
|---|---|---|
| 功率 P | **放电为正**（P>0 = 电池放电、向电网输出） | 充电 P<0 |
| 并网点功率 P_PCC | **送电为正**（向电网输出为正） | 与 P 同向 |
| 无功 Q | 发出为正（容性） | 本课程不展开，见 AVC 课程 |
| SOC | 0~1 无量纲 | 正文用 %（如 80%），代码用 0~1 |
| 能量 E | 放电为正、充电为负的**累计**量 | 收益计算取绝对值 |
| 可充/可放能量 | **非负幅值** | 不带符号，表示"还能充多少/还能放多少" |

## B.2 单位约定

| 量 | 单位 |
|---|---|
| 功率 P | MW（正文）/ MW 或 kW（代码一律 MW） |
| 能量 E | MWh |
| 电价/成本 | 元/kWh 或 元/MWh（正文统一用 元/kWh 便于心算） |
| 时间 t | h（小时） |
| 效率 η | 无量纲（0~1） |
| SOC/SOE | 无量纲（0~1） |
| 需量 | MW（按 15 min 平均） |

## B.3 贯穿场景参数（[教学示例]）

| 参数 | 符号 | 值 | 说明 |
|---|---|---|---|
| 额定功率 | P_nom | 50 MW | 充/放对称 |
| 额定能量 | E_nom | 100 MWh | LFP 电芯 |
| SOC 工作范围 | — | 10%~90% | 可用能量 E_avail = 80 MWh |
| 充电效率 | η_chg | 0.95 | 单程 |
| 放电效率 | η_dis | 0.95 | 单程 |
| 往返效率 | η_rt | 0.9025 ≈ 0.90 | η_chg × η_dis |

## B.4 分时电价表（[教学示例]）

| 时段 | 时间 | 电价（元/kWh） |
|---|---|---|
| 谷 | 23:00–08:00（9 h） | 0.35 |
| 平 | 08:00–10:00、12:00–17:00、21:00–23:00（9 h） | 0.70 |
| 峰 | 10:00–12:00、17:00–21:00（6 h） | 1.20 |

峰谷价差 = 0.85 元/kWh。

## B.5 关键公式

| 公式 | 含义 |
|---|---|
| E_store = E_grid × η_chg | 充电：电网吸收 E_grid，电池存入 E_store |
| E_out = E_store × η_dis | 放电：电池放出 E_store，并网输出 E_out |
| SOC(t+1) = SOC(t) + (P_chg×η_chg − P_dis/η_dis)×Δt / E_nom | SOC 递推（P 带符号时用统一式） |
| 套利收益 = Σ(E_dis_i × price_i) − Σ(E_chg_j × price_j) | 日收益 |
