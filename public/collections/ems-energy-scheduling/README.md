# 储能能量管理与经济调度

> 从分时电价到日前优化排程的决策闭环 · 50MW/100MWh 储能电站贯穿主线

## 课程定位

面向储能 EMS 开发者的**能量调度与经济决策**进阶课程。你已经通过 `ems-python-learning` 掌握了电池/BMS/PCS 基础，通过 `bess-soc-advanced-plus` 掌握了 SOC/SOE/SOP 能力估计，通过 `ems-primary-frequency-regulation` 和 `ems-agc-regulation` 掌握了有功-频率的执行，通过 `ems-avc-regulation` 掌握了无功-电压的执行。本课程补上 EMS 名字里 "Energy Management" 的字面核心——**什么时候充、什么时候放、放多少、按什么价格交易**。

**零基础要求**：会 Python，了解 SOC 概念（本课程第 04 章会复习并直接复用）。不需要运筹学背景，第 05 章的线性规划会用贪心特解讲透。

## 统一方向约定

全课程放电为正（P>0 放电、P<0 充电）；并网点送电为正；SOC 用 0~1（正文用 %）；功率单位 MW/kW、能量单位 MWh/kWh；时间单位 h。详见 [附录B](附录B_符号规范.md)。

## 学完能做什么

读完本课程，你应能：

1. 手算分时电价下一充一放、两充两放的日收益，判断套利是否划算；
2. 计算需量管理与储能削峰后的电费节省；
3. 手算光储协同下的计划跟踪与功率平滑效果；
4. 由 SOC/SOP 约束推导储能的**可行充放电区间**，识别"想放但放不出"的边界；
5. 用贪心/LP 建模日前充放电排程，并解释为什么分段电价下贪心即最优；
6. 实现日内滚动修正，量化预测误差带来的收益损失；
7. 评估现货市场报价与辅助服务叠加的容量权衡；
8. 复盘实际收益，把"计划收益 vs 实际收益"的偏差归因到各环节。
