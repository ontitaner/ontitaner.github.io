# 储能 EMS 业务、原理与工程实践教程

面向**有软件开发经验、零电力背景**，准备进入储能 EMS（Energy Management System）软件开发的工程师。本教程不从 Python 语法开始，而是围绕“业务目标 → 电力模型 → EMS 架构 → 控制算法 → 仿真验收 → 综合项目”建立完整的工程心智模型。

**入口章节**：[00 储能电站运行概览与 EMS 学习导引](00_导读_储能站的24小时.md)

## 教程主线

```text
00 一座光储站的一天
  ↓
01～07 电网、功率、电池、PCS、电站拓扑与功率平衡
  ↓
08～10 EMS 架构、控制流水线、通信与数据质量
  ↓
11～18 控制原语、可行域、套利、需量、调频、AVC、仲裁与分配
  ↓
19～20 闭环仿真、故障注入、验收证据、可观测性与安全
  ↓
21 端到端综合项目：让简化 EMS 跑完一天
```

全课程的统一方向约定是：**储能放电为正、充电为负；并网点向电网送电为正、从电网取电为负；无功向电网发出为正**。完整定义见[附录 B：符号与功率方向规范](附录B_符号与功率方向规范.md)。

## 学完能做什么

- 读懂储能站的功率流、测量平面、点表和设备职责边界；
- 区分 BMS、PCS、EMS、PCC、调度和保护系统的职责；
- 实现限幅、死区、滞回、Ramp、滤波、PI、可行域投影和状态机；
- 实现峰谷套利、需量控制、一次调频、AGC、AVC、命令仲裁和多 PCS 分配；
- 处理数据冻结、过期、丢包、设备拒绝、离线、重启和时钟跳变；
- 用带容差、统计窗口、持续时间和需求追踪的断言形成验收证据；
- 完成一个可以运行 24 小时、具有对照组和测试证据的简化 EMS。

## 安装与运行

要求 Python 3.10 或更高版本。进入 `lab` 目录安装运行依赖：

```powershell
python -m pip install numpy matplotlib pytest
```

常用命令：

```powershell
# 在 ai_build/ems-python-learning/lab 目录执行
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
$env:PYTHONDONTWRITEBYTECODE='1'
python -m pytest -q -p no:cacheprovider

# 运行一个最小闭环示例
$env:PYTHONPATH='.'
python examples/ch19_sim_trace.py
python examples/ch20_observability_trace.py
python examples/ch21_one_cycle_trace.py

# 在 ems-python-learning 目录执行文档和配图检查
python figures/check_figure_numbers.py
python figures/check_mermaid.py 19_仿真与测试.md
```

教学示例采用“输入 → 算法 → 输出 → 自检”结构；测试既验证手算，也验证异常场景、需求追踪、图文标注和全天验收。`00` 章是导读，不单独设置实验脚本；`grid_sim.py` 是第 15 章的低阶教学模型，有独立边界测试，但不代表真实电网仿真。

## 适用范围与工程边界

课程中的仿真是 **EMS 级离散时间仿真**，用于验证方向、控制逻辑、约束、时序、降级和恢复。它不验证 PCS PWM/电流环、电磁暂态、谐波、真实继保、消防联锁、现场通信性能或并网试验结果。带 `[教学示例]` 的参数不代表现场整定值；现场必须以设备资料、项目设计、合同、调度规程和最新适用标准为准。
