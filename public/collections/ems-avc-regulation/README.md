# EMS AVC自动电压控制：从调度电压目标到无功闭环执行的工程实现

本课程面向储能/新能源场站 EMS 开发者、并网调试工程师与电站运维人员，系统阐述 AVC（自动电压控制）在新能源场站侧的技术要求与工程实现。课程从并网点电压-无功物理关系出发，沿四种控制模式（定 Q、定 PF、Q-U 下垂、定电压 PI）逐级下沉至 EMS 的多资源无功分配、P-Q 能力校核、IEC104 指令链路与 PCS/SVG 执行，最终以电压合格率、无功调节速率与响应时间三项指标闭环到月度考核结算与辅助服务市场收益分析。

课程内容以 DL/T 1867《电力系统自动电压控制技术规范》、DL/T 1707《电力系统电压和无功电力技术导则》等技术标准为骨架，补充 EMS 侧的工程实现视角。文中引用的规程条款仅作为理解口径，现场参数一律以项目适用的调度规程与并网协议为准。

**入口章节**：[00 AVC自动电压控制：从调度电压目标到全场无功出力的闭环控制链路](00_AVC闭环控制链路.md)

## 学完能做什么

- 拿到一份新的省网 AVC 调度细则，能在 30 分钟内定位到影响 EMS 开发的条款；
- 独立完成四种 AVC 控制模式（定 Q、定 PF、Q-U 下垂、定电压 PI）的工程选型与代码落地；
- 设计风光储异构场站的无功分配策略，处理 PCS 的 P-Q 能力约束、SVG 的独立响应与 OLTC 的慢速协调；
- 诊断 AVC 月度考核中电压合格率与无功调节速率不合格的根因——定位到通信延时、整定参数还是设备能力瓶颈；
- 设计 AVC 并网联调试验方案，用带时标的四时刻数据（目标下发/子站接收/设备响应/稳态达标）形成可追溯的验收证据链；
- 在储能无功机会成本与 SVG 独立配置之间做出经济性决策。
