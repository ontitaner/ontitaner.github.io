## B.5 方向约定

**统一规定（全课程一致）**：

- **Q > 0（正）**：发出无功（容性），使电压升高
- **Q < 0（负）**：吸收无功（感性），使电压降低
- **P > 0（正）**：发电/放电（储能向电网输出有功）
- **ΔU > 0**：电压偏高，需要吸收 Q（Q < 0）
- **ΔU < 0**：电压偏低，需要发出 Q（Q > 0）
- **PI 输出**：当 ΔU > 0 时 PI 输出负值（吸收），当 ΔU < 0 时 PI 输出正值（发出）
- **基准电压**：除非特别标注，所有标幺值以 PCC 额定线电压为基准
- **Q 限幅值域**：全课程统一为对称 ±Q_max（除非明确标注独立限幅）
