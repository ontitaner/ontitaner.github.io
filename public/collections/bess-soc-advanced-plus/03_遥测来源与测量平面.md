# 03 遥测来源与测量平面

## 3.1 运行场景

16:30，EMS 开始准备晚峰能力重算。采集界面同时显示：BMS 侧单体电压约 3.30 V、簇直流电流、PCS 侧交流功率和 PCC 出口功率。值班员将这些数值导出后发现，BMS 直流功率、PCS 交流功率和 PCC 功率并不相同。

若把直流侧可用能量直接当成交流侧可交付能量，计划会高估效率损失；若把单体电压和簇端电压混在同一模型里，参数辨识会失去物理含义；若不统一功率方向，充电会被误认为放电。

## 3.2 决策困难

17:30 的能力计算需要把 BMS、PCS 和 PCC 数据放进同一条链，但它们来自不同测量位置、单位和时间语义。EMS 首先要确认“这个数是什么”，再确认“它能否与另一个数相加、比较或换算”。

这就是测量平面和数据契约的必要性。没有统一口径，SOC、SOE 和 SOP 都可能在输入阶段失真。

## 3.3 数据口径

| 字段 | 内部口径 | 来源 | 常见错误 |
|---|---|---|---|
| `current_a` | A，放电为正 | BMS | 各算法自行猜方向 |
| `voltage_v` | 代表性单体 V | BMS/BMU | 单体电压与簇端电压混用 |
| `temperature_c` | °C | BMS | 忽略原始倍率 |
| `soc` | 0–1 | BMS/估计器 | 将 50 与 0.50 混用 |
| `p_batt_dc_kw` | 直流侧功率 | BMS | 当作交流侧功率 |
| `p_pcs_ac_kw` | PCS 交流侧功率 | PCS | 忽略 PCS 效率 |
| `p_pcc_kw` | 并网点功率 | PCC/EMS | 忽略站用电和出口限制 |

## 3.4 测量平面

| 平面 | 典型量 | 用途 | 与晚峰任务的关系 |
|---|---|---|---|
| 单体 | 单体 V、支路 I | OCV、RC、SOC 模型 | 判断电池内部状态 |
| 直流侧 | `p_batt_dc_kw` | BMS 能力 | 电池可提供的内部功率 |
| 交流侧 | `p_pcs_ac_kw` | PCS 执行 | 可转换到交流的功率/能量 |
| 并网点 | `p_pcc_kw` | 调度履约 | 最终对电网实际交付 |

状态模型使用代表性单体电压和支路电流；履约判断使用 PCC 或 PCS 交流侧功率。跨平面换算必须显式包含串并联关系、效率和站用电。

## 3.5 算法需求

后续数据质量、状态估计与能力算法要求每个输入都携带：

```text
数值 + 单位 + 方向 + 测量平面 + 时间 + 质量状态 + 来源
```

否则算法无法判断 3.30 是单体电压还是簇端电压，2000 kW 是 PCS 功率还是 PCC 功率，也无法判断效率应乘在何处。

## 3.6 手算示例

换算链的通用形式如下，`N_s` 为串联数、`N_p` 为并联簇数，见附录 A.8：

```text
E_cell = C_cell·V_cell/1000          （单体名义能量，kWh）
E_site = E_cell·N_s·N_p            （站级名义能量，kWh）
E_ac   = E_dc·η_DC→AC              （交流侧可交付，kWh）
```

单体额定容量 314 Ah、标称电压 3.2 V、416 串、12 簇。

**第 1 步：单体换算到站级名义能量。**

```text
E_cell = 314 Ah×3.2 V/1000 = 1.0048 kWh
E_site = 1.0048×416×12 = 5015.96 kWh
```

**第 2 步：直流侧换算到交流侧。**

```text
E_dc = 0.692 MWh
E_ac = 0.692×0.931 = 0.644 MWh
```

效率只在跨直流/交流平面时乘一次。重复乘效率会低估可交付能量；完全不乘则高估。

## 3.7 业务决策

| 当前决策 | 必须使用的平面 | 原因 |
|---|---|---|
| 是否触发 SOC 校正 | 单体电压/支路电流 | 对应 OCV 和 RC 模型 |
| 是否允许继续放电 | BMS 直流能力 | 对应电池保护事实 |
| 是否能完成 2 MW 任务 | PCS/PCC 交流功率与能量 | 对应电网交付口径 |
| 是否需要扣效率 | 跨 DC→AC 时 | 只在平面切换处处理 |

第 04 章将继续处理：即使测量平面正确，若电流和电压不是同一时间窗口，模型仍会把数据解释错。
